## 5. 공개 신청·상담 화면의 처리

백엔드 저장 기능을 새로 만들지 않는다는 범위를 지켰다.

- 과정 신청: 시연 화면이며 입력 내용이 서버에 저장·접수되지 않음을 화면에 표시하고 임시저장·제출 버튼을 비활성화했다.
- 기업 문의: 데모 입력이며 서버에 저장·접수되지 않음을 표시하고 최종 제출 버튼을 비활성화했다.
- 상담: 과정 선택기가 없는 상담 화면에서 공통 스크립트가 null 요소에 접근하던 잠재적 JavaScript 오류를 최소 수정했다. 상담 제출은 서버 미연결 상태를 표시하고 비활성화했다.
- 민감 입력을 실제 접수처럼 보이게 하거나 임의의 로컬 접수 번호를 생성하지 않는다.

## 6. 역할과 SuperAdminPolicy 정리

현재 런타임 Role은 `TRAINEE`, `INSTRUCTOR`, `ADMIN` 3종이다.

- 현재 구현: 강사 `INSTRUCTOR`, 관리자 `ADMIN`
- 현재 특례: `ADMIN` 중 일부 로그인 ID에 `SuperAdminPolicy`가 적용되어 계정 자격증명 변경 같은 제한된 작업만 별도 통제
- 현재 미구현: `AdminLevel`, 운영관리자/최고관리자 별도 Role, Permission, DataScope
- 미래 설계: `ADMIN` 내부의 운영관리자와 최고관리자를 `AdminLevel + Permission + DataScope` 등으로 구분할 수 있는 설계안

따라서 `SuperAdminPolicy`는 현재의 별도 최고관리자 Role이나 완성된 관리자 등급 체계가 아니다. 두 관리자를 미래에 분리하는 내용도 현재 구현 사실이 아니다. 관련 IA와 권한 매트릭스 문서를 이 기준으로 수정했으며 SecurityConfig, Role, DB, 실제 정책 코드는 변경하지 않았다.

권한 재검증 결과 강사가 아래 관리자 전용 경로에 직접 접근하면 모두 403이다.

- `/admin/courses`
- `/admin/users/pending`
- `/admin/admins`
- `/admin/settings/reminder`

- 수강생·관리자·강사 모바일 내비게이션과 백드롭
- modal이 화면 밖으로 벗어나지 않는지

### 브라우저 개발자 도구

- Console: uncaught error, null 접근, 중복 id 경고
- Network: CSS/JS/image 404, 로그인 POST/CSRF, redirect chain

이 수동 시각 검수 미완료는 기술적 `MERGE READY` 판정과 분리하며, 실제 대외 배포 전에는 반드시 완료한다.

## 12. 최종 이슈 분류

## 13. 병합 전 마지막 조건

현재 소스 상태는 기술적으로 **MERGE READY**다. 다만 아직 커밋되지 않았으므로 실제 병합 전에는 다음 순서가 필요하다.

1. 위 수동 화면을 직접 확인한다.
2. `outputs/`, `참고문서/`를 제외하고 의도한 코드·문서·테스트만 통합 브랜치에 커밋한다.
3. 원격 통합 브랜치에 올릴지 검토한 뒤 별도 승인 하에 push/merge한다.

이 문서는 기술 통합 준비 판정이며 실제 운영 콘텐츠 검수나 대외 배포 승인을 대신하지 않는다.
