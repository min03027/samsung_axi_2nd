DAILY IMMERSION

하루의 리듬이
몰입을 만듭니다.

목표를 정하고, 배우고, 직접 만들고, 함께 점검합니다. 수업이 끝난 뒤에도 필요한 학습과 질문을 이어갈 수 있도록 하루를 설계합니다.

  1. 08:40 01 · START

    아침 목표

    오늘 완성할 결과와 개인 목표를 확인하고 우선순위를 정합니다.

  2. 09:00 02 · LEARN

    수업

    핵심 개념과 실제 사례, 강사의 시연을 통해 문제 해결의 기준을 세웁니다.

  3. 13:00 03 · BUILD

    실습

    개인 실습 환경과 과정별 장비를 사용해 배운 내용을 직접 구현합니다.

  4. 16:30 04 · REVIEW

    팀 점검

    작업물을 함께 살펴보고 피드백과 다음 행동을 구체적으로 정리합니다.

  5. 19:00 05 · GROW

    야간 학습·튜터링

    부족한 부분을 보완하고 남은 질문은 자율학습과 튜터링으로 이어갑니다.

※ 하루 흐름을 이해하기 위한 예시이며 실제 수업·실습·튜터링 시간은 과정과 기수에 따라 달라집니다.
