02
Why AXI

왜 삼성AXI였나요?

전문대에서 이공계열로 졸업해 IT를 전반적으로 배우긴 했지만, 수업에서 다루는 내용이 너무 광범위해서 정말 원하던 웹 개발 분야에만 집중하기가 쉽지 않았습니다. 다양한 기술을 배웠어도 실제 업무에 적용 가능한 기술을 다루는 시간이 생각보다 부족해, 웹 개발을 더 심도 있게 배우고 전문성을 키우고 싶어 부트캠프를 듣게 되었습니다.

삼성AXI는 원래 알던 곳은 아니고 기관을 찾아보다 알게 됐는데, 기관과 기숙사 모두 서울 근처라 면접 보러 다니기 접근성이 좋을 것 같아 선택하게 되었습니다.

03
Process

과정은 어땠고, 무엇을 배우셨나요?

부트캠프의 집중적이고 실무 지향적인 학습 덕분에 원하는 분야의 지식을 많이 쌓을 수 있었습니다. 웹 개발에 특화된 기술을 탄탄하게 배우며 기초부터 실무까지 빠르게 적응할 수 있었어요.

가장 배우고 싶었던 HTML·CSS 같은 기본 웹 기술부터 React 같은 프레임워크·라이브러리까지 학습하며 실전 기술을 익혔고, 꿈을 이룰 수 있겠다는 확신이 들 때마다 정말 뿌듯하고 행복했습니다.

04
After

수료 후에는 어떻게 지내시나요?

부트캠프를 수료하자마자 새마을금고에 취업했고, 회사에서 웹 개발 기술을 활용하며 계속 성장하고 있습니다. 취업 지원 강사분들께서 꼼꼼하게 자소서 첨삭도 도와주셔서 큰 도움이 됐고, 팀 프로젝트로 만든 포트폴리오 외에 개인 포트폴리오까지 만들어둔 덕에 해냈다고 생각합니다.

05
Message

마지막으로 하고 싶은 말이 있다면.

이전에는 다소 막연했던 웹 개발 분야가 머릿속에 확실히 자리 잡았고, 이제는 자신감 있게 프로젝트를 수행할 수 있게 되었습니다. 저처럼 IT 전체를 다 듣느라 한 분야에 집중할 기회가 없었던 분들이라면, 더더욱 삼성AXI에서 KDT 부트캠프를 들어보셨으면 좋겠습니다! 저만큼이나 취업을 위해 힘써주신 강사분들께도 정말 감사드립니다.
