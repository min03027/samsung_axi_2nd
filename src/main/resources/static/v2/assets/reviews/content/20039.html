02
Why AXI

왜 삼성AXI였나요?

중학생 때 학교에서 IT 기업 특강을 들은 후부터 IT 분야에 관심이 생겼습니다. 처음에는 어떤 방향으로 나아가야 할지 몰랐는데, 꿈에 대해 고민하며 흥미를 찾다가 당X마켓·토X 등 자주 쓰는 앱 개발자들의 인터뷰 영상을 보고 앱 개발을 해보고 싶다는 생각이 들어 삼성AXI에서 앱 개발 교육을 수강하게 되었습니다.

사실 삼성AXI라는 기관도 설명회에 갔다가 처음 알게 되었는데, 선생님께서 자세히 설명해주셔서 좋았고, 기숙사도 있고 아침저녁으로 식사도 제공된다고 해서 마음에 들어 선택하게 되었습니다.

03
Process

과정은 어땠고, 무엇을 배우셨나요?

앱 개발이나 IT 학원을 다녀본 적도 없고 IT 수업이 처음이라 초반에는 따라가는 게 힘들었지만, 강사님들이 기초부터 쉽게 알려주시고 기존에 하던 공부와 다르다는 점에서 점점 흥미를 느껴 더 배우고 싶다는 열정이 생겼습니다.

커리큘럼이 앱 개발 기초부터 심화까지 짜여 있었고, 실제 앱을 만드는 팀 프로젝트도 여러 번 진행하다 보니 많은 것을 배울 수 있었습니다. 업계에서 필요로 하는 Java 등 프로그래밍 언어를 배우며 직접 앱을 개발하다 보니 금방 재미가 붙었고, 선생님들께서 상담도 꼼꼼히 진행해주셔서 고민할 틈 없이 수업에 집중할 수 있었습니다.

“
실제 앱을 만드는 팀 프로젝트를 여러 번 진행하다 보니, 많은 것을 배울 수 있었습니다.
04
After

수료 후에는 어떻게 지내시나요?

교육 수료 후, 배운 앱 개발 기술과 포트폴리오를 바탕으로 한화생명에 애플리케이션 관련 업무 분야로 취업했습니다.

05
Message

마지막으로 하고 싶은 말이 있다면.

1년 동안 삼성AXI에서 좋은 수업을 들으며 실제 앱 개발 경험도 해보고 실무에 필요한 기술도 얻으면서, 앱 개발자로서의 자신감을 얻었습니다. 원래 꿈도, 하고 싶은 것도 없어서 그 자체로 고민이 많았는데 삼성AXI 덕에 인생의 갈피를 잡은 것 같아 정말 기쁩니다. 앱 개발에 관심 있는 분이라면, 저처럼 삼성AXI에서 실무 경험을 쌓고 원하는 기업에 취업하실 수 있으면 좋겠습니다.
