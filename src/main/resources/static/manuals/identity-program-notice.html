인증 환경 사전 고지

지금 필요한 준비물은 웹 브라우저와 스마트폰뿐입니다. 별도 프로그램을 설치하지 않습니다. 아래 안내는 외부 OTP 연동 전 현재 운영 기준입니다.

1. 지원 환경

기기별 지원 브라우저
기기 권장 브라우저 확인된 제약
PC (Windows / macOS) Chrome 최신, Edge 최신 웹캠·화면 공유·모니터 확인 모두 사용 가능
PC (macOS) Safari 화면 공유와 확장 디스플레이 확인이 제한될 수 있습니다
PC Firefox 화면 공유 선택 화면과 전체화면 동작이 Chrome과 다릅니다
스마트폰 (iPhone) Safari 신분증 촬영·앨범 선택용입니다. 시험 응시는 PC로 합니다
스마트폰 (Android) Chrome 동일

브라우저 확인 불가 항목

확장 디스플레이(듀얼 모니터) 확인은 screen.isExtended 기능을 쓰는데, 이 기능을 지원하지 않는 브라우저에서는 「확인 불가」로 표시됩니다. 확인 불가는 통과로 처리하지 않으며, 감독관이 직접 확인합니다.

2. 설치가 필요한 프로그램

현재 흐름 — 설치 없음

신분 확인은 QR 코드로 열리는 웹 페이지에서 진행합니다. 스마트폰에 앱을 설치하지 않고, PC에도 감독용 프로그램을 설치하지 않습니다. 필요한 것은 브라우저와 카메라뿐입니다.

외부 OTP 인증은 아직 연동되지 않았습니다. OTP 사업자가 선정되면 전용 앱 설치나 문자 인증 절차가 추가될 수 있습니다. 현재는 사업자와 앱이 확정되지 않았으므로 이 문서에 특정 앱 이름을 적지 않습니다. 연동 시점에 이 문서가 갱신되며, 갱신 전에는 QR 방식만 사용합니다.

현재와 향후 절차 비교

단계 현재 외부 OTP 연동 후
본인 확인 수단 운영 중 신분증 사진 + 얼굴 사진 예정 휴대폰 본인인증 또는 OTP 추가
확인 주체 운영 중 운영진이 직접 대조·승인 예정 외부 기관 인증 결과 병행
필요 프로그램 운영 중 없음 (브라우저만) 예정 사업자 정책에 따라 결정

3. 허용해야 하는 권한

브라우저가 아래 권한을 물어봅니다. 거부하면 해당 단계를 진행할 수 없습니다.

권한 사용 기기 쓰이는 곳
카메라 스마트폰 신분증 촬영
사진 / 앨범 스마트폰 미리 찍어 둔 신분증 사진 선택
카메라 PC 웹캠 연결 확인, 입장 직전 얼굴 사진 1장 촬영
화면 공유 PC 화면 공유 가능 여부 확인 (공유 대상은 직접 선택)
팝업 / 새 창 PC 이 안내 문서와 매뉴얼 열기

권한을 잘못 거부했다면

  1. 브라우저 주소창 왼쪽의 자물쇠(또는 아이콘)를 누릅니다.
  2. 「사이트 설정」에서 카메라·화면 공유 권한을 초기화합니다.
  3. 페이지를 새로 고치고 다시 시도하면 권한 요청이 다시 나타납니다.
웹캠 영상은 서버로 전송되지 않습니다. 브라우저에서 연결 여부만 확인하고, 서버에는 «확인한 시각»만 기록합니다. 녹화하지 않습니다. 제출되는 사진은 훈련생이 직접 촬영 버튼을 눌러 동의한 얼굴 사진 1장뿐입니다.

4. 네트워크와 보안 연결

  • 시험 도중 네트워크가 끊겨도 답안과 남은 시간은 유지됩니다. 다시 접속하면 같은 회차로 이어집니다.
  • 스마트폰과 PC가 같은 Wi-Fi에 있어야 QR로 연 페이지가 열립니다.
  • 스마트폰에서 localhost 주소는 PC가 아니라 스마트폰 자신을 뜻합니다. QR에 담긴 주소를 그대로 사용하세요.

HTTP와 HTTPS 차이

브라우저는 카메라·화면 공유를 보안 연결(HTTPS) 또는 localhost에서만 허용합니다. 일반 http:// 주소로 접속하면 브라우저가 카메라를 차단하며, 이는 오류가 아니라 정상 보안 정책입니다.

접속 주소 PC 카메라·화면 공유 스마트폰 신분증 촬영
https:// 운영 주소 사용 가능 사용 가능
http://localhost 사용 가능 해당 없음 (PC 전용)
http:// 사내망 IP 차단됨 — 정상 정책 대체로 사용 가능

5. 개인정보 수집·이용 안내

항목 내용
수집 항목 신분증 사진 1장, 입장 직전 얼굴 사진 1장, 제출 시각, 제출 기기의 IP
수집 목적 온라인 시험 응시자 본인 확인 및 부정응시 방지
보관 방법 웹에서 직접 접근할 수 없는 비공개 저장소에 보관합니다. 촬영 위치·기기 정보(EXIF)는 저장 전에 제거합니다.
열람 범위 운영 관리자, 그리고 해당 시험을 담당하는 강사만 열람할 수 있습니다. 담당하지 않는 강사는 접근이 거부됩니다. 열람 사실은 감사 기록에 남습니다.
보관 기간 기관이 정한 보관 기간이 지나면 파일이 자동 파기됩니다. 파기 후에는 조회할 수 없습니다. 구체적인 보관 일수는 기관 정책으로 확정한 뒤 이 문서에 반영합니다.
제3자 제공 제공하지 않습니다. 외부 OTP 사업자 연동 시에는 연동 전에 별도 고지합니다.
동의 거부 동의하지 않으면 신분 확인을 진행할 수 없고, 감독이 필요한 시험에 응시할 수 없습니다.
주민등록번호는 수집하지 않습니다. 신분증을 촬영할 때 주민등록번호 뒷자리가 보이면 가린 뒤 촬영해 주세요. QR 주소에도 이름·주민등록번호·사용자 번호가 들어가지 않습니다.

6. 문제가 생겼을 때

증상 확인할 것
QR을 스캔했는데 페이지가 열리지 않음 PC와 스마트폰이 같은 Wi-Fi인지 확인하세요. QR은 10분 뒤 만료되므로 다시 발급하세요.
QR이 만료됨 신분증 제출 전이라면 「QR 재발급」으로 새 QR을 받으세요. 이미 제출했다면 재발급이 필요하지 않습니다.
PC에서 카메라가 켜지지 않음 주소가 https:// 또는 localhost인지 확인하세요. 다른 프로그램이 카메라를 쓰고 있으면 종료하세요.
실수로 권한을 거부함 위 3장의 「권한을 잘못 거부했다면」 절차를 따르세요.
얼굴 사진 제출이 실패함 네트워크를 확인하고 다시 제출하세요. 실패해도 다시 촬영·제출할 수 있습니다.
확장 디스플레이 확인이 「확인 불가」 브라우저가 이 기능을 지원하지 않습니다. 감독관에게 모니터 구성을 직접 확인받으세요.
운영진 승인이 오래 걸림 제출 후 운영진이 직접 대조합니다. 승인 후 30분 안에 입장해야 합니다. 지나면 다시 확인받아야 합니다.

7. 문의

본인 확인 절차와 개인정보 처리에 관한 문의는 담당 강사 또는 교육 운영 담당자에게 해 주세요. LXP 화면의 「고객 지원」 메뉴에서도 문의를 남길 수 있습니다.

문의할 때 아래 정보를 함께 알려 주시면 확인이 빠릅니다.

  • 사용한 기기와 브라우저 (예: Windows Chrome, iPhone Safari)
  • 화면에 표시된 안내 문구 그대로
문의할 때 신분증 사진을 첨부하지 마세요. 개인정보를 가린 화면 사진만 보내 주세요.
