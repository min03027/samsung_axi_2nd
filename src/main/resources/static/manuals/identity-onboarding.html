본인인증 안내

문서 버전 1.0 · 기준일 2026-08-24 · 대상: 훈련생, 강사, 운영 관리자

이 화면은 안내 문서입니다. 여기서 인증이 완료되지 않습니다. 최초 로그인 시 본인인증을 서버가 강제하는 기능과 외부 인증 식별값 저장은 아직 구현되지 않았습니다. 이 문서에는 「인증 완료」 버튼이 없으며, 브라우저에 완료 표시를 남겨 인증한 것처럼 보이게 하지도 않습니다.

1. 왜 본인인증을 하는가

국비 지원 훈련 과정은 수강생 본인이 직접 학습하고 응시했다는 사실을 증빙해야 합니다. 대리 수강·대리 응시가 확인되면 훈련 이수와 지원금에 문제가 생깁니다.

그래서 LXP는 두 지점에서 본인을 확인합니다.

  • 로그인 — 계정이 본인 것인지 (아이디·비밀번호)
  • 시험 입장 — 지금 화면 앞에 앉은 사람이 그 계정의 주인인지 (신분증·얼굴)

로그인만으로는 두 번째를 알 수 없습니다. 계정을 빌려주면 로그인은 통과하기 때문입니다. 그래서 감독이 필요한 시험에서는 신분증과 얼굴을 따로 확인합니다.

2. 언제 인증하는가

시점 확인 방법 현재 상태
최초 로그인 휴대폰 본인인증 등 외부 수단 서버 강제 미구현
일반 시험 입장 비밀번호 재확인 (최근 30분 내 인증 시 면제) 운영 중
감독 시험 입장 QR 신분증 + 얼굴 사진 + 운영진 승인 운영 중
시험 중 재접속 최초 입장 때 확인한 기록을 그대로 인정 운영 중
시험 도중 네트워크가 끊겨 다시 접속하면 신분 확인을 다시 하지 않습니다. 최초 입장 때의 확인 시각이 그대로 보존되며, 재접속 사실은 별도 기록으로 남습니다.

3. 예상 단계

최초 로그인 본인인증이 연동되면 아래 순서가 될 예정입니다.

  1. 로그인 발급받은 아이디와 비밀번호로 로그인합니다. 현재 동작
  2. 본인인증 안내 확인 수집 항목과 목적을 확인합니다. 이 문서
  3. 외부 본인인증 수행 휴대폰 본인인증 또는 OTP로 실명을 확인합니다. 사업자 선정 후
  4. 인증 결과 저장 인증 기관이 돌려준 식별값을 계정에 연결합니다. 서버 연동 필요
  5. 학습 시작 인증을 마친 계정으로 과정을 수강합니다.
3·4단계가 없으므로 현재는 로그인 직후 바로 학습을 시작할 수 있습니다. 이 문서는 절차를 미리 알려 주는 안내이며, 인증을 대신하지 않습니다.

4. 수집하는 식별값

지금 수집하는 것

항목 언제 목적
신분증 사진 1장 감독 시험 입장 전 응시자 본인 확인
얼굴 사진 1장 감독 시험 입장 직전 신분증과 대조
접속 IP·시각 로그인·제출·입장 시 접속 이력 관리
본인확인 시각·수단 시험 입장 시 응시 증빙

연동 후 수집이 예상되는 것

외부 본인인증을 연동하면 인증 기관이 발급하는 연계 식별값을 계정에 저장하게 됩니다. 어떤 값을 어떤 형태로 받을지는 사업자 선정 후에 확정되므로 지금 구체적으로 적지 않습니다. 확정 시 이 문서와 개인정보 처리방침을 함께 갱신하고, 수집 전에 별도 동의를 받습니다.

주민등록번호는 수집하지 않습니다. 신분증을 촬영할 때 주민등록번호 뒷자리를 가린 뒤 찍어 주세요.

5. 역할별 접근 범위

역할 볼 수 있는 것 볼 수 없는 것
훈련생 본인의 사전점검 상태, 본인이 제출한 자료의 제출 여부 제출한 신분증·얼굴 사진 이미지 자체, 다른 훈련생의 모든 정보
강사 본인이 담당하는 시험의 신분확인 대기열·상세·이미지·판정 담당하지 않는 시험의 자료 (접근 시 거부됨)
운영 관리자 전체 시험의 신분확인 자료와 판정 이력 파기된 자료 (보관 기간 경과 후)

권한 없이 접근하면

  • 로그인하지 않은 상태로 관리자 주소를 열면 로그인 화면으로 이동합니다.
  • 담당하지 않는 시험의 상세 주소를 직접 입력하면 접근 거부 안내 화면이 표시됩니다.
  • 이미지 주소만 알아도 권한 없이 열 수 없습니다. 요청마다 권한을 다시 확인합니다.
  • 있는 자료와 없는 자료를 화면에서 구별할 수 없게 처리해, 다른 사람의 자료 존재 여부를 알 수 없습니다.
운영진이 신분증 이미지를 열어 본 사실도 기록됩니다. 누가 언제 어떤 자료를 조회했는지 감사 이력으로 남습니다.

6. 세 가지 기록의 차이

이름이 비슷해 혼동하기 쉬운 세 가지 기록입니다. 목적과 보존 이유가 다릅니다.

기록 남는 내용 쓰이는 곳
접속 기록 로그인·로그아웃 시각, 접속 IP, 본인인증 성공 시각 계정 도용 확인, 학습 시간 산정 근거
신분확인 기록 제출한 자료, 제출 시각, 검토자, 승인·반려 시각과 사유 응시자가 본인이었음을 증빙
부정행위 기록 전체화면 해제, 탭 이탈·복귀, 복사·붙여넣기 시도, 재접속 응시 환경 이상 여부 판단

세 기록은 서로를 대체하지 않습니다. 예를 들어 부정행위 기록에 아무것도 없더라도 그것이 «본인이 응시했다»는 증거가 되지는 않습니다 — 그것은 신분확인 기록이 담당합니다.

7. 실패했을 때

상황 해결
비밀번호를 잊었다 로그인 화면의 비밀번호 찾기를 사용하거나 운영 담당자에게 초기화를 요청하세요.
시험 입장 시 「본인인증이 필요합니다」 최근 30분 내 인증 이력이 없습니다. 비밀번호를 다시 입력하세요.
비밀번호를 맞게 넣었는데 실패한다 대소문자와 키보드 언어를 확인하세요. 반복 실패 시 담당자에게 문의하세요.
신분증이 반려되었다 반려 사유가 화면에 표시됩니다. 재제출 요청을 받으면 다시 제출할 수 있습니다.
재제출 횟수를 모두 썼다 운영 담당자에게 문의하세요. 추가 재제출은 운영진 판단이 필요합니다.
계정이 본인 것이 아닌 것 같다 즉시 운영 담당자에게 알리고 비밀번호를 변경하세요. 접속 기록으로 확인할 수 있습니다.

8. 아직 연동되지 않은 부분

숨기지 않고 그대로 적습니다. 아래는 현재 동작하지 않습니다.

항목 현재 필요한 것
최초 로그인 본인인증 강제 서버가 강제하지 않음 — 로그인 후 바로 학습 가능 서버 인증 게이트와 미인증 계정 차단 로직
외부 인증 식별값 저장 저장 항목·형식 미정 인증 사업자 선정과 계정 연결 설계
휴대폰 본인인증 / OTP 미연동 외부 사업자 API 계약
실시간 영상 감독·녹화 미연동 — 웹캠은 연결 확인과 사진 1장까지 WebRTC 송출·저장 백엔드
화면 공유 서버 강제 브라우저에서만 확인 서버 검증 API
웹캠에 관하여: 서버는 영상 프레임을 받지 않습니다. 브라우저가 확인한 결과를 서버가 받아 적은 시각만 기록합니다. 따라서 이 기록은 「카메라가 켜져 있었다」는 강한 증거가 아니라 응시 흐름을 확인하기 위한 것입니다. 감독관 확인과 함께 사용해야 합니다.

9. 문의

계정·인증·개인정보 처리에 관한 문의는 교육 운영 담당자에게, 과정 내용과 시험 문항에 관한 문의는 담당 강사에게 해 주세요. LXP 화면의 「고객 지원」 메뉴에서도 문의를 남길 수 있습니다.

문의 시 아이디와 발생 시각을 알려 주시면 접속 기록으로 빠르게 확인할 수 있습니다.

문의할 때 비밀번호나 신분증 사진을 보내지 마세요. 운영 담당자는 비밀번호를 묻지 않습니다.
