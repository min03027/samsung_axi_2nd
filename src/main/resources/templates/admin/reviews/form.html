후기 등록

동의 범위를 넘어서는 개인정보는 공개 API에서 자동 제외됩니다.

목록

오류

기본

사용자 계정의 실명 대신, 동의받은 홈페이지 표시명을 별도로 저장합니다.

교육·취업 연결

과정과 기업 마스터를 참조하지만, 협력 관계와 실제 취업 사실은 서로 다른 데이터입니다.

실감형 인터뷰

카드의 짧은 본문 외에 상세 페이지에서 보여 줄 변화 과정을 구조화합니다.

미디어

운영 스토리지가 확정되지 않아 이미지와 영상은 URL로 연결합니다.

노출

공개 설정뿐 아니라 홈페이지 공개 동의와 사용 상태가 함께 충족되어야 실제 노출됩니다.

공개 설정을 켜도 ‘홈페이지 후기 공개 동의’가 없으면 공개 API에서 제외됩니다.

노출 동의

각 동의는 독립적으로 기록되며, 동의하지 않은 미디어·취업 정보는 공개 DTO에 포함되지 않습니다.

내부관리

관리자 메모는 공개 API에 포함되지 않습니다.
