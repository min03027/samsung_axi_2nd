주간 성장 리포트

훈련생의 실제 진도·권장 진도·출석·미완료 과제와 시험을 한 번에 집계해 알림함과 이메일로 보냅니다.

자동 발송
일마다1~30일 사이에서 운영 일정에 맞게 설정할 수 있습니다.
시매시간 확인하며 설정 시각 이후 아직 발송하지 않은 리포트를 보냅니다.
권장 진도보다 %p 이상 낮을 때해당 훈련생에게 학습 계획 점검 문구를 제공합니다.

지금 확인하기

대기하지 않고 현재 학습 기록으로 리포트를 만들어 훈련생 알림함에 바로 보냅니다. 훈련생은 알림의 상세 보기를 누르면 성장 리포트 화면으로 이동합니다.
