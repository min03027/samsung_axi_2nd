현재 모집 상태 사전 상담

모집 준비도

필수 정보가 모두 준비됐습니다.
  • 누락 항목

1. 기본 정보

내부 과정 식별 정보와 홈페이지에서 과정의 목적을 설명할 공개 정보를 입력합니다.

내부 운영 참고용이며 공개 화면에는 한줄소개와 공개 대상 정보만 사용합니다.

2. 모집 일정

모집 회차마다 달라지는 날짜입니다. 교육 시작일과 구분해 관리합니다.

3. 선발 정보

홈페이지 과정 상세에서 지원자가 확인할 절차와 준비물을 입력합니다.

4. 교육 운영

교육 기간·시간·방법을 관리합니다. 주차별 과정은 저장 후 상세 화면의 과목/차시 기능을 그대로 사용합니다.

5. 비용·지원

무료 과정도 빈칸 대신 0원을 입력해야 모집 준비 완료로 판단합니다.

6. 강사진

담당 교사는 과정 저장 후 상세 화면에서 실제 INSTRUCTOR 계정을 배정합니다.

7. 프로젝트·성과

기업·기관 마스터에 등록된 참여사를 연결합니다. 기존 자유입력 값은 이전 데이터 호환을 위해 보존됩니다.

Ctrl(Windows) 또는 Command(macOS)를 누른 채 여러 기관을 선택할 수 있습니다.
위 선택 항목을 저장하면 공개 화면에서는 선택된 기관명이 우선 표시됩니다.

8. 홈페이지 노출

모집중이면서 홈페이지 노출이 켜진 과정만 공개 목록에 나타납니다.

9. 과정 상태

교육 운영 상태는 기존 LMS 기능에 사용됩니다. 홈페이지 모집 상태는 상세 화면의 순차 전환 버튼으로만 변경합니다.
