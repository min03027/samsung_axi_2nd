자동 이수 기준

과정별로 필요한 목표값을 저장하세요. 모든 적용 기준을 충족한 훈련생만 자동 이수 처리됩니다.

테스트 평균을 비워두면 점수는 판정에서 제외됩니다. 테스트 평균을 적용하면 미확정 평가가 없는지도 함께 확인합니다.

이수 현황 엑셀 다운로드 통과한 훈련생은 수료 상태로 전환되고 이수증이 즉시 활성화됩니다.
